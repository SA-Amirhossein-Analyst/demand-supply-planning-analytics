## 📊 Dataset

This project uses the following Kaggle dataset:

**High-Dimensional Supply Chain Inventory Dataset**  
Source: [Kaggle – High-Dimensional Supply Chain Inventory Dataset](https://www.kaggle.com/datasets/ziya07/high-dimensional-supply-chain-inventory-dataset)

The dataset contains simulated daily, SKU-level supply chain data covering areas such as:

- Units Sold
- Inventory Levels
- Supplier Lead Times
- Reorder Points
- Order Quantities
- Promotions
- Stockout Events
- Unit Cost and Unit Price
- Forecasted Demand
- Warehouse and Regional information

The dataset is designed to simulate realistic supply chain and inventory-management scenarios and can be used for demand forecasting, inventory control, stockout-risk analysis, cost analysis, and supply chain optimization.

### 🎓 Educational / Portfolio Purpose

This project is primarily an **educational and portfolio project**.

The dataset is simulated and is therefore **not intended to represent the actual operations, financial performance, inventory policies, or supply-chain decisions of a real company**.

The purpose of using this dataset is to demonstrate an end-to-end analytical workflow and to practice applying supply-chain concepts to structured data.

The project focuses on learning and demonstrating:

- Data cleaning and transformation
- Inventory KPI calculation
- Demand and forecast-error analysis
- Inventory coverage analysis
- Reorder-point monitoring
- Stock-risk classification
- Recommended-order calculations
- Procurement and inventory analytics
- Python-based data analysis
- Excel-based analysis


### ⚠️ Data & Modeling Note

Some derived fields and calculations in this project are created or adjusted for **educational and analytical purposes**.

For example, derived KPIs such as:

- `Inventory_Gap`
- `Inventory_Status`
- `Forecast_Error`
- `%_Forecast_Error`
- `Inventory_Cover_Days`
- `Stock_Risk`
- `Sales_Value`
- `Gross_Margin`
- `Recommended_Order`

are calculated as part of this project and should not be interpreted as official metrics from the original dataset.

Where assumptions are introduced, they are documented in the project methodology.

The objective is to demonstrate how supply-chain data can be transformed into **decision-support insights**, rather than to claim real-world operational accuracy.
